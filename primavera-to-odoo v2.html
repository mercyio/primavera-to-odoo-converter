📌 How to Automatically Create New Projects & Stages in Odoo:
1. Project Auto-Creation
When Odoo shows "No matching record found" for Project, select 🔘 Create new values under "When a value cannot be matched". Odoo will create the project automatically.
2. Stage Auto-Creation
For the Stage column, also select 🔘 Create new values so all Kanban stages are created automatically without errors.
3. Save Settings in Odoo
Click Import or save the mapping template in Odoo so it remembers to auto-create new projects and stages for all future imports.
